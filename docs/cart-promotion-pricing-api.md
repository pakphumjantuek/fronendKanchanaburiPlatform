# ตะกร้าสินค้าและการคิดราคาโปรโมชัน (Flutter API Guide)

เอกสารนี้อธิบายการใช้ตะกร้าสินค้าชุดเดียวกับเว็บ โดย base URL คือ `.../api` และทุกเส้นต้องส่ง `Bearer token` ของผู้ซื้อ

## หลักการคิดราคา

ลูกค้าสามารถเลือกจำนวนสินค้าได้ถึงสต็อกที่มีอยู่ แม้จำนวนที่เลือกจะมากกว่าสิทธิ์โปรโมชัน

- จำนวนที่อยู่ในสิทธิ์โปรโมชัน คิดในราคาลด
- จำนวนที่เกินสิทธิ์โปรโมชัน คิดในราคาปกติ
- Backend เป็นผู้ตัดสินจำนวนและราคาเสมอ แอปมีหน้าที่แสดงข้อมูลที่ API ส่งกลับ

ตัวอย่าง: สินค้าราคาปกติ `100` บาท เหลือสิทธิ์โปรโมชัน `2` ชิ้น ราคาดีล `80` บาท เมื่อลูกค้าเลือก `5` ชิ้น จะได้ `2 x 80 + 3 x 100 = 460` บาท

## API ตะกร้า

### ดูตะกร้า

`GET /cart`

```json
{
  "cartId": "guid",
  "total": 460,
  "items": [
    {
      "cartItemId": "guid",
      "productId": "guid",
      "shopId": "guid",
      "shopName": "ร้านชุมชน",
      "productName": "สินค้าตัวอย่าง",
      "imageUrl": "/uploads/products/example.jpg",
      "quantity": 5,
      "availableQuantity": 8,
      "originalPrice": 100,
      "unitPrice": 80,
      "dealQuantity": 2,
      "normalQuantity": 3,
      "dealUnitPrice": 80,
      "normalUnitPrice": 100,
      "dealType": "FlashDeal",
      "dealDiscountValue": 20,
      "dealEndsAt": "2026-09-22T14:00:00Z",
      "subtotal": 460
    }
  ]
}
```

ความหมายฟิลด์สำคัญ:

| ฟิลด์ | ความหมาย |
| --- | --- |
| `quantity` | จำนวนทั้งหมดที่ลูกค้าเลือก |
| `availableQuantity` | จำนวนสต็อกที่ซื้อได้สูงสุด ใช้เป็นค่า max ของตัวเลือกจำนวนสินค้า |
| `dealQuantity` | จำนวนที่ได้ราคาดีลจริงในตะกร้าขณะนั้น |
| `normalQuantity` | จำนวนที่คิดราคาปกติ |
| `dealUnitPrice` | ราคาต่อชิ้นของส่วนที่ได้โปรโมชัน |
| `normalUnitPrice` | ราคาต่อชิ้นของส่วนที่คิดปกติ |
| `subtotal` | ยอดรวมของรายการนี้ ซึ่งคำนวณจากสองส่วนแล้ว |
| `total` | ยอดรวมสินค้าทุกรายการในตะกร้า ยังไม่รวมค่าจัดส่ง |

ให้แสดงแยกราคา เช่น `ราคาพิเศษ 2 ชิ้น x ฿80` และ `ราคาปกติ 3 ชิ้น x ฿100` หากค่าจำนวนนั้นมากกว่า `0` และใช้ `subtotal`/`total` จาก API โดยตรง

### เพิ่มสินค้า

`POST /cart/items`

```json
{
  "productId": "guid",
  "quantity": 5
}
```

### ปรับจำนวนสินค้า

`PUT /cart/items/{cartItemId}`

```json
{
  "quantity": 5
}
```

### ลบสินค้า

`DELETE /cart/items/{cartItemId}`

หลังเพิ่ม ปรับจำนวน หรือลบ ให้เรียก `GET /cart` ใหม่ทันที เพื่อรับยอด ราคา และการแบ่งสิทธิ์ล่าสุด ไม่ต้องคำนวณเองใน Flutter

## Checkout และกรณีสิทธิ์เปลี่ยน

`POST /orders/checkout`

ส่งเฉพาะข้อมูล checkout ตาม API เดิม ห้ามส่งราคา, ราคาดีล หรือจำนวนสิทธิ์จากแอปไปยืนยันยอด

ก่อนสร้างออเดอร์ Backend จะคำนวณสต็อก เวลาโปรโมชัน และสิทธิ์ที่เหลืออีกครั้งภายใน transaction เดียวกัน:

- ถ้ายังมีสิทธิ์ ระบบสร้างรายการออเดอร์แยกเป็นส่วนราคาดีลและส่วนราคาปกติให้เอง
- ถ้าสิทธิ์ถูกผู้ใช้อื่นใช้ไปก่อน ยอดส่วนที่เหลืออาจเปลี่ยนเป็นราคาปกติ
- ถ้าสต็อกไม่พอ หรือข้อมูลถูกแก้ไขพร้อมกัน API จะตอบข้อผิดพลาด ให้โหลดตะกร้าใหม่และแจ้งลูกค้า

ดังนั้น ก่อนกด checkout และเมื่อ API ตอบผิดพลาด ให้ refresh `GET /cart` แล้วแสดงยอดล่าสุดเสมอ

## ข้อควรแสดงผลใน Flutter

- `availableQuantity` จำกัดด้วยสต็อกเท่านั้น ไม่ใช่สิทธิ์ดีล; ลูกค้ายังเพิ่มจำนวนเกินสิทธิ์ดีลได้ในราคาปกติ
- แสดงป้าย `โปรโมชันพิเศษ` หรือ `โปรเด็ดชุมชน` จาก `dealType` เมื่อ `dealQuantity > 0`
- หาก `dealQuantity = 0` ให้ซ่อนส่วนราคาโปรโมชัน แม้สินค้านั้นเคยมีดีล
- วันเวลา `dealEndsAt` ให้ตีความเป็น UTC หาก API ไม่มี suffix timezone แล้วแสดงเป็นเวลาไทย UTC+7
